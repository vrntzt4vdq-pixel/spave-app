# Spave Fintech Dashboard

Spave is a responsive fintech web app that helps users track spending, manage budgets, and save automatically.

## Features
- Onboarding screens
- Transaction tracking
- Safe-to-spend calculation
- Smart budget alerts (75% / 90%)
- Savings automation (7.5%)
- Responsive design

## Tech Stack
- HTML
- CSS
- JavaScript

## How to Use
1. Open the app
2. Add transactions
3. Track your balance and savings
